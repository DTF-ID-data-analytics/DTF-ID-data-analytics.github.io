# DTF Infrastructure Division — Static GitHub Pages site

A lightweight static landing page for GitHub Pages.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive layout, typography and light/dark split effect
- `script.js` — pointer-following split and theme control

## Deploying

Place the three files in the root of the GitHub Pages repository and configure
GitHub Pages to deploy from the appropriate branch/folder.

## Customising projects

Update the four `.project-card` links in `index.html` with the actual project URLs.

## Interaction

By default the page uses a live split:

- left of the pointer = dark
- right of the pointer = light

The Theme button cycles through split, light and dark modes.
